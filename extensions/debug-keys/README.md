# debug-keys

Print raw terminal key data for debugging Pi extension key handling.

## Usage

Type `/debug-keys on` and start typing to see JSON-escaped raw key data. Add a positive count, such as `/debug-keys on 2`, to stop automatically after that many keystrokes.

## Installation

This is a `pi` extension. Run [`/pie-kumar303-config`](../../README.md#install) to install it.
